## 官方简介摘要

讨论 Kubernetes、基础设施调度器和 AI 框架之间的整合缺口，重点介绍 Ray、Slurm、PyTorch，以及 Kubernetes DRA 与 Workload API 之间的跨项目协作。

它将“双重调度”和工作负载无法感知硬件的问题放到完整生态中分析，并展示如何连接工作负载语义与加速器分配。

- 技术关键词：Kubernetes、DRA、Workload API、Ray、Slurm、PyTorch、Double Scheduling
- 学习主线：AI 框架 → Workload API → 编排器 → 设备
