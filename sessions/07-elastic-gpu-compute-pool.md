## 官方简介摘要

介绍把分散 GPU 集群联合成统一弹性计算池的全局调度设计，并扩展 Kubernetes DRA 与 Kueue，以解决应用级拓扑、故障转移放置和跨集群资源建模问题。

## 为什么值得关注

这是从单集群资源分配走向十万 GPU 级训练与推理全局编排的生产实践。

- 技术关键词：Multi-cluster、GPU Pool、DRA、Kueue、Topology、Failover、Federation
- 学习主线：设备模型 → 集群调度 → 全局调度域
