## 官方简介摘要

介绍 OpenTelemetry eBPF Instrumentation（OBI）如何在网络层无侵入捕获 Agent 行为，包括 MCP Streamable HTTP、JSON-RPC Tool Call、Embedding、Reranking 和多轮 LLM–Tool 交互，并映射到 OpenTelemetry GenAI 语义规范。

## 为什么必须关注

它展示了传统网络和 eBPF 可观测性如何迁移到 AI Agent。无需修改每个 Agent 或工具服务，就有机会观察跨模型、MCP 和外部工具的完整调用链，非常适合从网络基础设施进入 AI Infra 的学习路线。

- 技术关键词：OBI、eBPF、OpenTelemetry、MCP、JSON-RPC、Embedding、Reranking、GenAI SemConv
- 学习主线：网络流量 → Agent/Tool 行为 → 分布式 Trace → 故障定位
