## 官方简介摘要

把 AI Agent 视为继虚拟机、容器之后的新型工作负载单元。Agent 不只有模型调用，还包含身份、记忆、目标、工具权限、执行状态和外部影响能力，因此需要声明式配置、策略化工具访问、可观测决策路径、隔离执行、持久状态、持续评估和人工介入机制。

## 为什么值得关注

这场 Keynote 给出了“Agent Native Infrastructure”的整体视角：如何复用 Kubernetes 的开放接口、Reconciliation Loop、可组合原语和 Policy as Code，避免 Agent 基础设施演变成封闭的专有控制层。

- 技术关键词：AI Agent、Agent Runtime、Policy as Code、Isolation、Observability、Human-in-the-loop
- 学习主线：容器工作负载 → Agent 工作负载 → 身份与策略 → 隔离与可观测性
