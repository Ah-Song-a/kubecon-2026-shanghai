## 官方简介摘要

使用 Cluster API 声明式创建和管理面向不同硬件与软件目标的底层集群，包括 GPU AI 集群、高速网络集群和专用存储集群。架构支持版本化供给、专用硬件隔离、空闲节点跨集群再平衡、OpenStack 服务集成和多 Region 扩展。

## 为什么值得关注

它把 Kubernetes 的声明式控制扩展到 OpenStack 与物理基础设施层，直接回应 GPU、高速网络和存储资源池如何按工作负载目的拆分、重组和复用的问题。

- 技术关键词：OpenStack、Cluster API、Bare Metal、GPU Cluster、High-Speed Networking、Multi-Region
- 学习主线：物理资源 → 声明式 Underlay → 专用 AI 集群 → 动态资源再平衡
