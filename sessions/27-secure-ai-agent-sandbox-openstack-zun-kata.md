## 官方简介摘要

面向执行 LLM 生成代码的高风险场景，以 OpenStack Zun 管理临时容器生命周期，以 Kata Containers 提供硬件级隔离，并组合 Glance 镜像管理和 Neutron 租户网络，构建可扩展的 Agent 执行 Sandbox。

## 为什么值得关注

它与仓库中的 Kubernetes Agent Sandbox、零信任流量治理和 runc 防护形成互补：从 OpenStack 原生视角展示镜像、网络、编排与轻量虚拟机隔离如何组成端到端安全边界。

- 技术关键词：AI Agent Sandbox、OpenStack Zun、Kata Containers、Glance、Neutron、MicroVM
- 学习主线：不可信代码 → 临时执行环境 → 网络隔离 → 硬件级安全边界
